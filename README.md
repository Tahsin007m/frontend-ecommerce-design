# RedStore: E-commerce Website

A responsive front-end e-commerce landing page for a sports and fitness store, built with pure HTML and CSS.

## Features

- Hero section with a call-to-action button
- Navigation bar with logo, menu links, and cart icon
- Featured categories showcase
- Featured Products and Latest Products grids with star ratings and prices
- Exclusive offer section highlighting the Smart Band 4
- Customer testimonials with ratings
- Brand logos section
- Footer with app download links, useful links, and social links

## Built With

- HTML5
- CSS3
- Google Fonts (Poppins)
- Font Awesome 4.7

## Project Structure

```
├── index.html      # Page structure and content
├── style.css       # Styling and layout
└── images/         # Logos, banners, product, category, and user images
```
